# Graph Navigator

**Author:** Ivan Petrov

## Description
Console application for working with graphs. Supports creation of directed, undirected, and weighted graphs, traversal algorithms (BFS/DFS), and shortest path finding (Dijkstra/BFS). Data persistence via JSON.

## Features
- Create Directed/Undirected/Weighted graphs
- Add/remove nodes and edges
- BFS and DFS traversal
- Shortest path finding (Dijkstra for weighted, BFS for unweighted)
- Save/Load graph to JSON file
- Input validation (unique nodes, positive weights)
- Object-Oriented design with Factory pattern

## Requirements
- Python 3.8 or higher
- No external libraries required (uses only standard library)
